# Регламент обработки сырых выгрузок (HTML/CSV) для анализа рынка

> Постоянный стандарт. Зеркальная копия — в репозитории Авитолога (`.claude/skills/avito-listing-packaging/references/market-raw-data-regulation.md`), с привязкой к его реальному пайплайну (`market-analyst`, `scripts/market_snapshot_analyzer.py`). Держать оба файла синхронно при следующей правке любого из них.

## Когда применяется

Поступил файл с поисковой выдачей (квартиры, новостройки, дома/коттеджи, вторичка) — обработать по 4 шагам, вернуть структурированную таблицу. Не для одного лота (это `messaging-persuasion.md`/`developer-listing-brief.md`) — для среза рынка/конкурентов.

## Шаг 1 — Фильтрация и очистка

Исключить: дубли, доли, объекты с некорректными ценами/площадями, **и объекты не по целевому ЖК/адресу/типу сделки**. Последнее — не гипотетический риск: Avito подмешивает в сохранённую страницу рекомендации по другим комплексам и аренду вместо продажи.

Зафиксировать явно: сколько карточек было в файле и сколько осталось, с разбивкой причин отсева по каждой (дубль / доля / некорректная цена или площадь / не тот ЖК-адрес / не та сделка). Не одна общая цифра «отсеяно N» без причин.

## Шаг 2 — Разметка по типу продавца (3 корзины)

Застройщик / Собственник / Агентство. Указать метод определения категории для конкретного источника:

- **Бейдж, если есть в разметке источника** — самый надёжный признак.
- **Бейджа нет (частый случай на Avito)** — косвенные признаки: рейтинг+число отзывов = профессиональный аккаунт; формулировки в тексте («от собственника»/«без комиссии» = частник, «от застройщика X» в третьем лице = посредник, не сам застройщик).

Каждую категорию — с уровнем уверенности: **подтверждено** (бейдж/прямое указание) или **предположительно** (косвенные признаки). Не сливать спорные случаи в чистую метку без пометки уверенности — категория «застройщик» по тексту иногда на деле оказывается переуступкой.

## Шаг 3 — Сводная коммерческая таблица

Markdown-таблица:

| Категория продавца | Кол-во лотов | Площадь мин-макс | Цена мин-макс | Средняя цена за м² (за сотку/м² дома — загородка) | Самый дешёвый прямой аналог |
|---|---|---|---|---|---|

Обязательно вне таблицы: **дата среза источника** (по дате файла) и **путь к исходному сырому файлу**, на основе которого построена таблица.

Поля, которые физически не извлекаются из источника (типовой случай — Avito обрезает описание до 256 символов, планировка/состав комнат не долистывает) — помечать явно **«НЕТ ДАННЫХ»**, не оставлять пустыми и не досочинять.

## Шаг 4 — Шорт-лист прямых альтернатив (2-3 объекта)

Максимально близкие к целевому лоту по характеристикам: площадь, состояние (под отделку/с ремонтом/с мебелью), готовность документов, ссылка на объявление.

## Сквозное правило — условная скидка застройщика

Применяется на любом шаге, где встречается цена от застройщика: проверить, не является ли отображаемая цена условной скидкой (100% оплата / конкретный тип ипотеки), которая может не действовать при реально предлагаемом покупателю виде финансирования — например, при семейной ипотеке. Не принимать отображаемую цену как окончательную без этой проверки.

## Формат выдачи

Строго таблица и краткий шорт-лист, без кода скриптов и технических логов.
