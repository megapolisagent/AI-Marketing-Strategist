# Регламент функций ИИ-агентов Avito — Авитолог и Трафик-менеджер (2026-09-01)

Источник: регламент от владелицы, дословно передан техническими блоками ниже. Директор ставит
задачи по смыслу (сегмент/приоритет/гипотеза), не пишет технику сама (вне контракта Advisory,
`HOME.md`). Прежде чем реальная задача уйдёт агенту через SendMessage — текст сначала показывается
владелице в чате, отправка только после явного «да» (`feedback_согласование_перед_отправкой_другим_агентам`).

## 1. Авитолог — контент, упаковка, органика, конверсия

### 1.1 База объектов и публикация (Autoload v4 & Items API)

| Функция | Польза | Пример задачи от директора |
|---|---|---|
| Генерация/выгрузка XML-фида по стандарту Avito (новостройки/вторичка/коммерция) | Не вручную по сотне полей на объект | «Сформируй фид по новому пулу из 25 квартир в ЖК, проверь обязательные поля, отправь на публикацию» |
| Анализ отчётов об ошибках публикации (`getLastSuccessfulUploadItems`) | Объявление не висит с ошибкой днями — правка за минуты | «Проверь отчёт последней выгрузки, покажи ошибки, исправь невалидные параметры» |
| Мгновенная правка цены по лоту (без перезагрузки всего фида) | Реакция на акцию застройщика без ожидания переиндексации | «Снизь цену на 300 000 ₽ по лоту №481516 на выходные — тест спроса» |

### 1.2 Рыночное позиционирование (Realty Analytics API)

Сверка цены объекта с оценкой алгоритма Avito по аналогам в локации — корректировка на 1-2% даёт
шильдик «Рыночная цена»/«Отличная цена» → бесплатный органический рост показов. Пример задачи:
«Проверь 10 наших 2-к квартир — какие подходят под плашку "Отличная цена" при коррекции 1,5%?»

### 1.3 Конверсия, удержание, репутация

| Функция | Польза | Пример задачи |
|---|---|---|
| Trigger-рассылка тем, кто добавил в «Избранное» | Дожим горячей базы, которая не позвонила сама | «По объектам с 15+ добавлений в Избранное за неделю — рассылка "скидка 2% при брони до конца недели"» |
| Мониторинг отзывов + автоответы | Держит рейтинг профиля, влияет на алгоритм выдачи | «На позитив — благодарность с приглашением в офис; на оценку ниже 4 — черновик с запросом деталей» |
| Анализ звонков/коллтрекинга (статус, аудиозаписи) | Контроль пропущенных, качество лидов отдела продаж | «Отчёт по пропущенным за вчера + записи 5 самых длинных разговоров по объекту X» |

## 2. Трафик-менеджер — платный трафик, аукцион, ставки, защита бюджета

### 2.1 Платное продвижение (VAS / BBIP v2)

| Функция | Польза | Пример задачи |
|---|---|---|
| Пакеты усиления (x2/x5/x10/x15/x20, на 1 или 7 дней) | Быстрый запуск продвижения по расписанию, без ручного клика | «x10 на 1 день — пяти флагманским 3-к в субботу в 09:00» |
| XL-формат / выделение цветом | Заметность в ленте среди конкурентов | «XL-формат для трёх пентхаусов на 7 дней» |

### 2.2 Ставки за действие (CPA/CPX)

| Функция | Польза | Пример задачи |
|---|---|---|
| Адаптивная ставка за просмотр/отклик/чат | Перебивает конкурентов в пик активности | «65 ₽ за целевое действие по всем студиям, пн-ср» |
| Dayparting (почасовое регулирование) | Экономия до ~30% бюджета на неэффективных ночных кликах | «+20% ставка 18:30-21:30 будни, остальное время — базовая» |

### 2.3 Защита бюджета и возврат средств

| Функция | Польза | Пример задачи |
|---|---|---|
| Автооспаривание спам-звонков/ботов (`createComplaint`) | Прямой возврат денег на баланс | «Списания за звонки короче 12 сек за неделю — на оспаривание» |
| Контроль остатка кошелька/лимитов | Упреждает внезапную остановку рекламы | «Уведомление, если баланс ниже 15 000 ₽» |

## 3. Сводная матрица — кто за что отвечает

| Направление | Авитолог | Трафик-менеджер |
|---|---|---|
| Объявления | Фид, тексты, фото, параметры, быстрые цены | Платные услуги (x5/x10/XL) на готовые карточки |
| Аукцион/ставки | Не управляет | CPX/CPA, аукцион по часам |
| База лидов | Рассылки по «Избранному», ответы на отзывы | Не взаимодействует с текстом сообщений |
| Аналитика | Рыночная оценка цены, просмотры, конверсия в контакт | Расход бюджета, CPL, возврат за спам |
| Финансы | Контроль целостности карточек | Баланс кошелька, списания, оспаривание спама |

## Приоритет сценариев (моё мнение — синтез уже собранного по делу, не новый источник; см. файлы 12, 13)

1. Шильдик «Рыночная/Отличная цена» (Авитолог) — бьёт в главный названный страх аудитории:
   недоверие к Avito (файл 12). Без риска бюджета.
2. Отзывы + упоминание закрытого Telegram-канала (Авитолог) — та же тема доверия + перенос на
   свой канал.
3. Дожим «Избранного» ипотечным оффером (Авитолог) — оффер уже готов в матрице волны 1 для
   крупнейшего сегмента (1-к, 24-25 млн).
4. A/B цены на студии/1-к нижний тир (Авитолог) — проверяет, «дорого» это про цену или про подачу.

**Не в приоритете — не хватает данных или не моё решение:** dayparting (нет данных о времени
активности сегмента именно на Avito, файл 12, «честно не закрыто»); порог CPL/бюджет — цифра
зависит от маржи владелицы, не сочиняется директором.

## Решения владелицы по двум открытым пунктам (2026-09-01)

**Dayparting (почасовые ставки):** не включаем сейчас. Первые 2-3 недели — базовые равномерные
ставки. Авитолог через API статистики/коллтрекинга собирает тепловую карту (в какие дни/часы
реально приходят целевые звонки/сообщения по нашим объектам). К настройке почасовых интервалов
возвращаемся, когда накопится реальный массив данных — не раньше.

**Порог CPL / отключение пакетов:** логика правила («если CPL выше нормы X дней подряд → снижать
ставку/отключать пакет») остаётся системным алгоритмом Трафик-менеджера. Конкретную цифру CPLmax
владелица задаёт сама в настройках — на основе комиссии со сделки и конверсии отдела продаж, не
директор.
