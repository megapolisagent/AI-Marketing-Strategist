# Протокол верификации цен перед публикацией на Avito (правило владелицы, 2026-09-01)

Причина: на Avito высокий процент заниженных фейковых объявлений («фонари») — цена из случайной
выборки без сверки с эталоном застройщика недостоверна. Правило жёсткое, обязательное для любого
лота перед тем, как цена уходит в `feed.xml`.

## Порядок (обязателен для Авитолога перед публикацией любого лота)

1. Строится верификационная таблица среза рынка — не разовая проверка, стандартный шаг.
2. Эталон — официальный прайс застройщика по корпусам (ASTERUS, ЖК ALIA) — верхняя/эталонная планка.
3. Срез рынка по сегментам (1-к, 2-к, 3-к) отдельно:
   - 10-15 реальных объявлений с прямыми ссылками на каждый сегмент;
   - разделение: сколько лотов от застройщика/официальных партнёров, сколько от собственников/
     инвесторов (переуступка);
   - отсечение явных заманух — цена за м² ниже эталона застройщика более чем на 15% без подтверждения
     не считается рыночной.
4. На основе таблицы — подтверждённый ценовой коридор, не единичная цифра из случайного объявления.

## Статус данных ÁLIA (2026-09-04)

Матрица волны 1 и черновики карточек по ÁLIA удалены владелицей как построенные на непроверенных
данных — весь предыдущий числовой материал по этому ЖК (конкретные лоты, цены, статус «единственный
проверенный лот») сброшен. Работа по ÁLIA начинается заново с нуля: сначала аналитика по 2-3-к
квартирам, без опоры на старые цифры. Официальный сайт застройщика для новой сверки —
`alia.moscow` (найден и подтверждён рабочим в `feedback_цены_только_с_сайта_застройщика`).
