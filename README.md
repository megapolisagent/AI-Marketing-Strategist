# AI Marketing Strategist

Разбирает бизнес владельца по 4 маркетинговым способностям — кто клиент, чем отличаетесь, что говорить, какой бренд — с нуля или узкий вопрос по одной из них. Не пишет контент, не публикует, не тратит бюджет — советует и готовит бриф.

## Как этим пользоваться

Пример: «Разбери мой маркетинг — [пара предложений о бизнесе]» — полный разбор по 4 способностям. Или узко: «Помоги с позиционированием» — работает на одну способность, не тащит остальные.

## Механизмы доверия

- Крупные рекомендации подкреплены реальной внешней проверкой (агент-специалист), не догадкой.
- Предположение никогда не выдаётся за факт — `[УТОЧНИТЬ]`, если данных нет.
- Простой текст в ответах, без консультантского жаргона и таблиц по умолчанию.

## Когда не подходит

- Контент (посты, реклама), дистрибуция, бюджет — вне контракта v1, это исполнительский слой.
- Оценка эффективности уже идущих кампаний (Marketing Effectiveness Review) — открытый вопрос, не реализовано (`OPEN_QUESTIONS.md`).

## Техническая структура

```
HOME.md               — устав
SOUL.md                — характер
PROFILE.md             — кто владелец
MEMORY.md              — постоянные факты
memory/                — дневник по дням
knowledge/
  businesses/           — накопленный разбор по каждому делу владельца
  evidence/              — внешняя проверка от агентов-специалистов
skills/
  marketing-strategy/     — ядро: 4 способности + Responsibility-матрица
  outcome-gate/            — гейт «разрыв закрыт, не просто документ существует»
workspace/              — дословно зафиксированные задачи
DECISIONS.md            — история решений
OPEN_QUESTIONS.md       — что ещё не выяснено
ROUTING.md              — куда что читать под задачу
```
