# AI Marketing Strategist — CMO

Директор по маркетингу: стратегия, воронка, позиционирование, смыслы — и личный бренд как прямая зона ответственности, не отдельная территория. Не пишет тексты и не крутит рекламу — ставит задачу специалистам-исполнителям и принимает результат по своим критериям.

## Как этим пользоваться

Пример: «Разбери мой маркетинг — [пара предложений о бизнесе]» — полный разбор. Или узко: «Помоги с позиционированием» — работает на одну способность, не тащит остальные.

Финальное решение всегда за владельцем: директор готовит стратегию с разложенными вариантами и аргументами, ждёт «да» на всё, что меняет курс — ничего не внедряется постфактум.

## Механизмы доверия

- Крупные стратегические решения подкреплены проверенной методологией (Dunford, Aaker, Moesta/Ulwick/Bourgoin — не догадкой) и, где нужно, реальной внешней проверкой.
- Предположение никогда не выдаётся за факт — `[УТОЧНИТЬ]`, если данных нет.
- Простой текст в ответах, без консультантского жаргона и таблиц по умолчанию.
- Работа специалиста (Авитолог, трафик-менеджер) не принимается автоматически — у директора свои критерии приёмки.

## Когда не подходит

- Написание текста, настройка рекламы, ведение кампании — исполнительский слой, не эта роль.

## Техническая структура

```text
CLAUDE.md              — кто агент, за что отвечает, как принимает решения
.claude/
  rules/                — постоянные правила (память, эпистемика, протокол делегирования, приоритет инструментов)
  skills/                — 12 методологий, физическая копия из Skill System
  agents/                — узкие субагенты (competitor-researcher, market-researcher, reviewer)
  settings.json           — permission-гейт: запуск субагента требует ручного подтверждения
PROFILE.md              — кто владелец, какой у него бизнес
MEMORY.md               — постоянные факты
memory/                 — дневник по дням + правки владельца
knowledge/
  businesses/            — накопленный разбор по каждому делу владельца
research/               — сырой материал внешней разведки (донорские репозитории скиллов)
```

Обычный markdown — любой файл можно открыть и прочитать напрямую.

## Мета

Собрано поверх Foundation-канона `.claude/rules/*.md` (тот же стандарт, что у ENGINEER). Роль — топ-уровневый CMO с личным брендом и обязательной приёмкой работы специалистов, не «советник по 4 способностям без контента/бюджета».
