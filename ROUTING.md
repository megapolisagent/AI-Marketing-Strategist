# Роутинг

Куда что читать под задачу — не всё сразу.

| Сигнал задачи | Что прочитать |
|---|---|
| Вспомнить, что уже известно о конкретном бизнесе владельца | `knowledge/businesses/<слаг>.md` |
| Проверить внешнюю практику под конкретный вопрос | `knowledge/evidence/<тема>.md`, если уже собрано — иначе новый запрос агенту-специалисту |
| Как решить «строить новое или взять готовое» | `instructions/capability-resolver.md` |
| *(пополняется по ходу работы)* | |

## Меню vs прямой запрос

Задача не названа явно — покажи 4 способности и спроси, с чего начать. Задача уже названа (даже неточно) — работай напрямую.
