- [Владелец визуал](memory/feedback_визуальный_формат.md) — любой структурный разбор/матрицу/сопоставление отдавать Markdown-таблицей, не сплошным текстом. Личное исключение из общего дефолта «простой текст без таблиц» — не менять устав под это.
- [Отправка другому агенту — отдельное «да»](memory/feedback_согласование_перед_отправкой_другим_агентам.md) — утверждение стратегии и разрешение отправить конкретный текст специалисту — два разных подтверждения, не одно. Полный протокол — `.claude/rules/delegation-protocol.md`.
- [Директор не гадает платформенную механику](memory/feedback_директорская_проактивность.md) — ЧТО/КОМУ говорить — зона директора; КАК устроена конкретная площадка технически — нет, называть нехватку и звать специалиста.
- [Готовую клиентскую прозу не производит](memory/feedback_messaging_voice_discipline.md) — несколько попыток написать текст голосом бренда провалились на практике; директор — структура и бриф, не финальная фраза. Также: никогда не строить текст на сравнении/превосходстве, любое число в клиентском тексте — только с проверенным источником.
- [План ≠ факт исполнения](memory/feedback_план_не_равно_факту_исполнения.md) — не называть план «готовым к запуску» без прямой сверки с исполнителем.
- [Спрос ≠ предложение](memory/feedback_спрос_не_равно_предложению.md) — при выборе районов/сегментов не путать метрики предложения (лотов, цены) с метриками спроса (экспозиция, поисковые запросы, конверсия).
- [Цены по ЖК — агрегаторы для первого прохода](memory/feedback_цены_только_с_сайта_застройщика.md) — но любая цифра перед публикацией сверяется с официальным сайтом застройщика.
- [Регламент застройщиков TrendAgent](memory/reference_trendagent_регламент_застройщиков.md) — реальный юридический статус «можно ли на Avito» — не по публичному сайту застройщика, а по таблице в `МЕГАПОЛИС ДАШБОРД\docs\02_legal\Трендагент\`.
- [Автоматику — после первого запуска](memory/feedback_автоматику_после_первого_запуска.md) — пороги/стоп-критерии не проектировать раньше первой реальной публикации с реальными цифрами. Recurring Pattern (2026-09-01 у Авитолога, 2026-09-18 у CMO).
- [Темп проверки бренд-имени](memory/feedback_темп_проверки_без_подтверждения.md) — при подборе имени не проверять следующего кандидата самой, ждать «проверь вот это» на каждое конкретное имя.
