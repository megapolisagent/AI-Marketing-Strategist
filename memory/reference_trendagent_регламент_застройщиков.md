Реальный статус «разрешает ли застройщик размещать его объекты на Avito/ЦИАН/Яндекс-Недвижимости» — не в открытом вебе, а в `МЕГАПОЛИС ДАШБОРД\docs\02_legal\Трендагент\` (папка называется «Трендагент» — по названию сети TrendAgent, источник регламента).

**Обновлено 2026-09-17:** старая структура из 5 файлов (полная таблица 263 застройщиков всех классов + риски + условия + два подсписка) удалена по решению владелицы и заменена одним выверенным файлом `01_застройщики-бизнес-премиум-москва.md` — 44 застройщика, сфокусировано на сегменте Бизнес/Премиум (единственный сегмент, который реально размещается на классифайдах). Полная версия с ролями/этапами процесса — `AI Marketing Strategist\.claude\skills\marketing-strategy\references\avito-operating-playbook.md`. Если встретится застройщик вне Бизнес/Премиум и его нет в новом файле — статус неизвестен, полного 263-справочника больше нет, не пытаться вспомнить старые цифры.

**Почему это важно:** публичные страницы застройщиков («работаем с агентствами», «партнёрская программа») — маркетинг, не юридический статус. На реальном деле (2026-08-31) три источника веб-research независимо назвали TEKTA (EVER), Level Group, Гранель, ЛСР, ПИК как «подтверждённых партнёров» на основе их сайтов — по факту все они в реальном регламенте TrendAgent значатся как **прямой запрет** на классифайды. Веб-поиск для этого вопроса не заменяет проверку реального документа.

**Как применять:** прежде чем рекомендовать конкретного застройщика для размещения на классифайдах (не только Avito) — сначала проверить эту папку, не веб-страницу застройщика. Если застройщика нет в таблице — прямо сказать «не в регламенте, статус неизвестен», не достраивать по аналогии с похожими застройщиками.
