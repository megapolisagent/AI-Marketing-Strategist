**Уточнено 2026-09-10:** агрегаторы (Циан, Avito, Новострой.ру, mskguru, proplanirovki и т.п.) —
нормальный источник для первого прохода/быстрой оценки по ЖК. Но это не отменяет финальную сверку:
прежде чем любая цифра (цена, площадь, акция, срок сдачи) уходит в публикацию/кампанию — она
проверяется на официальном сайте застройщика (или прямым звонком в отдел продаж). Агрегатор ускоряет
старт, не заменяет первоисточник на выходе.

Исходное правило (2026-09-01, до уточнения) было строже — агрегаторы не использовались вообще, только
сайт застройщика с первого захода. Ниже — почему это правило появилось; сама причина (риск
несовместимых цифр у агрегаторов) не изменилась, изменился только момент, когда обязательна сверка с
первоисточником — не на входе, а перед публикацией.

**Почему:** 2026-09-01, дело "агентство недвижимости", волна запуска Avito по ÁLIA. За один день
собрала у разных агрегаторов три несовместимых диапазона цен на одну и ту же 1-к квартиру (24,4 /
27,9 / из другого источника ещё иначе) и два разных общих числа квартир в проекте (760 / 2648).
Кампания была построена на этих цифрах и чуть не ушла в публикацию с неверными ценами. Официальный
сайт застройщика (`alia.moscow`) дал совместимую, куда более точную картину (точный адрес, реальные
сроки очередей, подтверждённая рассрочка 0%) с первого захода — просто не была найдена сразу
(попытка на неверный URL `asterus-development.com/alia/` дала 404, ошибочно решила, что данных нет).

**Как применять:** агрегаторы можно использовать сразу, для быстрого первого прохода по ЖК (ориентир
по цене, общее представление). Но прежде чем любая цифра о конкретном объекте (цена, площадь, акция,
срок сдачи) уходит в публикацию/кампанию — обязательна сверка на официальном сайте самого
проекта/застройщика (или звонком в отдел продаж). Если первый угаданный URL не открылся — не
сдаваться после одной попытки, искать точный адрес сайта отдельным запросом. Расхождение
агрегатор↔сайт застройщика — сигнал остановиться и разобраться, не усреднять цифры.

**Новый режим сбоя, 2026-09-12:** не только агрегаторы дают несовместимые цифры — один WebFetch-запрос
к самому сайту застройщика тоже может подвести. По ÁLIA (alia.moscow) я через WebFetch получила
названия башен «Панорама»/«Lighthouse», которых реальная разведка Авитолога (Apify, официальный
каталог, Avito/Циан) не нашла ни в одном источнике — скорее всего, WebFetch обработал не ту страницу
или его внутренняя суммаризация что-то домыслила. Эти названия успели уйти в бриф специалисту как факт
и чуть не создали путаницу «это два разных объекта». Реальные корпуса по ÁLIA: 1, 2, 3, 5, 6, 11, 13A,
13B, 10E, 10F; кварталы «Урбан-блок Сити 3», «Ривер 1».

**Как применять (дополнение):** WebFetch с сайта застройщика годится для общей ориентировки (класс,
район, застройщик, общий диапазон цен), но структурные факты уровня «названия корпусов/башен, точная
нумерация лотов» — нельзя передавать специалисту как подтверждённый факт без сверки с его собственной,
более тщательной разведкой (прямой доступ к площадке/API), если она у него есть и уже велась по этому
объекту. Один WebFetch-проход — это ПРЕДПОЛАГАЮ, не ЗНАЮ, даже когда источник — официальный сайт.
