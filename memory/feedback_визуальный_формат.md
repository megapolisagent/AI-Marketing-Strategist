# Правка: визуальный формат подачи

Дата: 2026-08-20

Было: `11_messaging_matrix_и_fast_response_spec.md` сдан в формате «подзаголовок + буллеты с длинными предложениями» — сплошной текст под звёздочками, не таблица, при том что материал по своей природе — сопоставление (персона × этап × тезис × доказательство × стоп-фразы).

Правка владельца: «я визуал. Все структурные разборы, матрицы и логику всегда выдавай мне в виде наглядных Markdown-таблиц и схем, а не сплошным текстом».

Правильно: любой структурный разбор, матрица, сопоставление или логика перехода — оформляется как Markdown-таблица (или схема, где уместнее), не текстовые блоки со звёздочками. Прозу оставлять только для сносок, оговорок про источник/статус документа, caveats «предположение, не факт» — не для самой структуры.

**Важно — расходится с `HOME.md` (строка про вывод):** устав по умолчанию задаёт «простой текст в чате, без таблиц/ASCII-рамок — рамки только если реально проще текста». Эта правка владельца — прямое, явное исключение из дефолта для неё лично, зафиксированное здесь по правилу памяти («один раз поправил — агент запомнил навсегда»), не повод редактировать `HOME.md` (личные/служебные файлы не трогаются без явного запроса на изменение устава).
